# 工具坐标系标定后精度优化程序库使用手册

## 0. 目标

本程序库用于在机器人工具坐标系初始标定完成后，进一步降低工具坐标系误差。

适用对象：

- 单个工具坐标系独立优化；
- 多吸盘、多工具、多标定靶场景；
- 工具定义形式为：工具坐标系在六轴末端坐标系下的位姿；
- 欧拉角定义为内旋 ZYX；
- 位姿顺序统一为：

```text
X, Y, Z, RX, RY, RZ
```

旋转矩阵定义：

```text
R = Rz(RZ) @ Ry(RY) @ Rx(RX)
```

---

## 1. 为什么建议拆成多个独立程序

建议采用：

```text
公共数学库 calib_common.py
+
多个独立功能脚本
```

而不是一个巨大程序。

原因：

1. 每个误差来源对应不同物理约束；
2. 每个程序的输入位姿含义不同；
3. PLC/HMI 集成时可以做成不同按钮；
4. 现场人员更容易按步骤操作；
5. 每个模块可以独立测试、独立验收；
6. 后期可以逐步替换某个模块，不影响其它功能。

本套程序包括：

```text
calib_common.py
01_tool_z_axis_direction_parallel_planes.py
02_tool_origin_xy_fixed_center.py
03_tool_origin_z_known_plane.py
04_tool_x_axis_direction_parallel_line.py
```

---

## 2. 推荐总流程

推荐对每个工具坐标系独立做优化，而不是必须先对齐到某个工具。

完整顺序为：

```text
1. Z轴方向优化：修 RX / RY
2. XY原点优化：修 X / Y
3. Z原点优化：修 Z，只有在有已知参考平面时才做
4. X轴方向优化：修绕Z轴的方向，只有工具有方向特征时才做
5. 最终验证
```

更具体：

```text
先修方向，再修位置。
先修 Z轴方向，再修 XY 原点。
如果 Z 原点对工艺不敏感，可以不修 Z。
如果工具是圆形/轴对称的，可以不修 X轴方向。
```

---

## 3. 各误差对应的物理现象

### 3.1 Z轴方向误差

现象：

```text
RZ旋转时，两个圆面出现异面夹角；
用塞尺扫一圈，间隙不一致。
```

对应误差：

```text
工具 RX / RY 不准确；
或者标定靶机械垂直度/安装倾斜。
```

解决程序：

```text
01_tool_z_axis_direction_parallel_planes.py
```

---

### 3.2 XY原点误差

现象：

```text
RZ旋转时，工具标定靶中心画圈；
百分表测侧跳有峰峰值。
```

对应误差：

```text
工具 X / Y 不准确。
```

解决程序：

```text
02_tool_origin_xy_fixed_center.py
```

---

### 3.3 Z原点误差

现象：

```text
工具到达同一平面时，实际高度不对。
```

对应误差：

```text
工具 Z 不准确。
```

解决程序：

```text
03_tool_origin_z_known_plane.py
```

前提：

```text
必须有已知参考平面方程。
没有已知参考平面，不能唯一确定绝对Z。
```

---

### 3.4 X轴方向误差

现象：

```text
工具Z轴正确，原点正确，但工具绕Z轴的方向不对；
例如非圆形工具、带槽工具、偏心吸盘、带方向的夹爪方向不准。
```

对应误差：

```text
工具 X / Y 轴方向，也就是绕Z轴的角度不准确。
```

解决程序：

```text
04_tool_x_axis_direction_parallel_line.py
```

前提：

```text
工具必须有非圆对称方向特征。
纯圆柱、纯圆盘没有X方向可观测性。
```

## 4. 程序1：Z轴方向优化

文件：

```text
01_tool_z_axis_direction_parallel_planes.py
```

### 4.1 目标

优化工具姿态：

```text
RX / RY
```

默认保持：

```text
X/Y/Z 不变
RZ 不变
```

### 4.2 输入位姿是什么

输入是：

```text
Tool[0] 下六轴末端坐标系在基坐标系下的位姿
```

也就是：

```text
B_T_6
```

格式：

```text
X, Y, Z, RX, RY, RZ
```

不是工具位姿。

### 4.3 现场怎么采

每一组：

1. 固定标定靶 b 不动；
2. 选择目标工具，例如 Tool[2]；
3. 改变 RZ 角度；
4. 调 RX/RY，使工具端标定靶 a 的接触面与固定标定靶 b 的接触面平行；
5. 不要求圆心重合；
6. 记录 Tool[0] 下六轴末端位姿；
7. 采 5～10 组，角度尽量分散。

### 4.4 数学原理

每一组面平行时：

```text
B_R_6_j @ z_6 = n_B
```

其中：

```text
z_6：工具Z轴在六轴末端坐标系下的方向
n_B：固定标定靶b的面法向，在基坐标系下固定不变
```

多组数据中：

```text
B_R_6_j @ z_6
```

应尽量指向同一个方向。

通过最大化：

```text
||sum(B_R_6_j @ z_6)||²
```

求出最一致的工具Z轴方向。

### 4.5 误差评价

程序输出：

```text
每组残差角度
RMS角度残差
Mean角度残差
Max角度残差
```

建议：

```text
< 0.05°：很好
0.05° ~ 0.15°：可用
0.15° ~ 0.30°：一般
> 0.30°：检查机械和操作
```

### 4.6 注意事项

1. 如果标定靶端面不垂直于圆柱轴线，程序会把机械误差写进工具姿态；
2. 如果气管拉扯，某些点应剔除；
3. 写入新姿态后必须重新采数据验证；
4. 不要用旧数据反复迭代。

## 5. 程序2：XY原点优化

文件：

```text
02_tool_origin_xy_fixed_center.py
```

### 5.1 目标

优化工具原点：

```text
X / Y
```

默认保持：

```text
Z 不变
RX/RY/RZ 不变
```

### 5.2 输入位姿是什么

输入是：

```text
Tool[0] 下六轴末端坐标系在基坐标系下的位姿
```

格式：

```text
X, Y, Z, RX, RY, RZ
```

不是工具坐标系在基坐标系下的位姿。

### 5.3 现场怎么采

前提：

```text
工具姿态 RX/RY/RZ 已经锁定。
```

每一组：

1. 选择目标工具；
2. 改一个 RZ 角度；
3. 不调 RX/RY；
4. 只平移 X/Y/Z，让工具标定靶中心对准固定中心；
5. 记录 Tool[0] 位姿；
6. 采 6～12 组，角度尽量分散。

### 5.4 数学原理

每次中心对准同一个固定点：

```text
P_B = p6_B_j + R_B6_j @ [X, Y, Z_old]
```

未知量：

```text
X, Y, P_X, P_Y, P_Z
```

多组数据用最小二乘求解。

### 5.5 误差评价

程序输出：

```text
RMS残差
Mean残差
Max残差
条件数
```

建议：

```text
RMS < 0.03 mm：很好
0.03 ~ 0.08 mm：较好
0.08 ~ 0.15 mm：可用
> 0.15 mm：检查采集或机械
```

条件数很大时，说明角度范围太小或数据分布不好。

### 5.6 注意事项

1. 采集时禁止主动调整 RX/RY；
2. 固定中心不能动；
3. 如果圆面仍明显异面，先回到程序1修 Z轴方向；
4. 写入新X/Y后必须重新采集验证。

## 6. 程序3：Z原点优化

文件：

```text
03_tool_origin_z_known_plane.py
```

### 6.1 目标

优化工具原点：

```text
Z
```

默认保持：

```text
X/Y 不变
RX/RY/RZ 不变
```

### 6.2 输入位姿是什么

输入是：

```text
Tool[0] 下六轴末端坐标系在基坐标系下的位姿
```

每组表示工具接触点接触到同一个已知参考平面。

### 6.3 必要前提

必须知道参考平面方程：

```text
n_B dot P_B = d
```

例如：

```text
基坐标系 Z=100mm 平面：
n_B = [0,0,1]
d = 100
```

如果不知道平面的绝对位置 d，不能唯一确定工具 Z。

### 6.4 数学原理

接触点在基坐标系下：

```text
P_B = p6_B + R_B6 @ p_contact_6
```

已知平面约束：

```text
n_B dot P_B = d
```

其中：

```text
p_contact_6 = [X_old, Y_old, Z_unknown] + R_6_tool @ contact_offset_tool
```

代入后可直接解出每组的：

```text
Z_i
```

多组取平均或剔除异常点。

### 6.5 注意事项

1. 没有已知平面不要用；
2. 如果Z方向对工艺不敏感，可以保持Z不动；
3. Z修正后建议重新验证XY。

## 7. 程序4：X轴方向优化

文件：

```text
04_tool_x_axis_direction_parallel_line.py
```

### 7.1 目标

优化工具绕 Z 轴的方向，也就是工具 X 轴方向。

### 7.2 什么时候需要

只有在工具存在方向特征时才需要，例如：

```text
夹爪
扁口吸盘
带槽结构
非圆工具
带刻线/平边的标定靶
```

如果工具是圆柱、圆盘、圆形吸盘，X轴方向通常不可观测，也不重要。

### 7.3 输入位姿是什么

输入是：

```text
Tool[0] 下六轴末端坐标系在基坐标系下的位姿
```

每组都要让工具X方向特征与固定直线/边/槽平行。

### 7.4 数学原理

每组方向平行时：

```text
B_R_6_j @ x_6 = q_B
```

其中：

```text
x_6：工具X轴在六轴末端坐标系下的方向
q_B：固定线方向，在基坐标系下固定不变
```

多组数据中：

```text
B_R_6_j @ x_6
```

应尽量一致。

求解方式与 Z轴方向完全类似。

### 7.5 注意事项

1. 没有非圆对称方向特征时不能用；
2. 建议先完成 Z轴方向优化；
3. 本程序保持 Z轴方向不变，只修 X/Y轴方向。

## 8. 是否当前方法已经是最优

在你当前约束下：

```text
无高精度外部三坐标
无激光跟踪仪
相机识别随机误差较大
希望现场可重复使用
```

这套方法是比较接近最优的工程方案。

原因：

1. 用物理约束替代相机结果；
2. 把姿态误差和位置误差拆开；
3. 每一步都有残差评价；
4. 支持异常点剔除；
5. 可迭代；
6. 可接入 PLC/HMI。

但它不是理论上的全局最优。

更高精度的升级方向：

```text
1. 专用高精度标定治具
2. 电接触探针
3. 力控接触检测
4. 固定显微相机测量
5. 三坐标/激光跟踪仪外部测量
6. 把点、线、面约束合成一个非线性最小二乘整体优化
```

其中第 6 项是软件上的下一代版本，但要求数据质量更高，否则容易把机械误差混进模型。

## 9. 精度方向优化建议

### 9.1 数据采集

1. 每个步骤采 5～12 组；
2. 角度尽量分散；
3. 每组独立重新对齐；
4. 不要只在很小角度范围内采；
5. 正转、反转都可测，用来检查气管拉扯和回差。

### 9.2 异常点剔除

每个程序都有：

```text
KEEP_BEST_N
```

建议：

```text
采 8 个点保留 6~7 个
采 12 个点保留 9~10 个
```

不要剔除太多，否则可能过拟合。

### 9.3 迭代

推荐：

```text
第一轮：粗修
第二轮：精修
第三轮：验证
```

如果三轮后不再改善，检查机械，不要继续算。

## 10. 简化方向优化建议

如果要让工厂人员快速使用，建议 PLC/HMI 做成流程按钮：

```text
按钮1：Z轴方向校正
    屏幕提示：
    请调到两圆面平行，按“记录点”
    重复5次
    点击“计算”
    显示新RX/RY和残差

按钮2：XY原点校正
    屏幕提示：
    请锁定姿态，只平移到中心重合，按“记录点”
    重复8次
    点击“计算”
    显示新X/Y和残差

按钮3：Z原点校正
    仅管理员模式，需输入参考平面参数

按钮4：X轴方向校正
    仅带方向特征工具使用
```

并且每一步都显示：

```text
RMS
Max
是否合格
是否建议重采
```

你可以把这个项目描述为：

机器人多工具坐标系精度优化工具库

Z轴方向误差、XY原点误差、Z原点误差、X轴方向误差。

## 12. 总结

最终推荐流程：

```text
1. Z轴方向：面平行约束 → RX/RY
2. XY原点：中心对准约束 → X/Y
3. Z原点：已知平面接触约束 → Z
4. X轴方向：线方向平行约束 → RZ/工具X方向
```

对应程序：

```text
01_tool_z_axis_direction_parallel_planes.py
02_tool_origin_xy_fixed_center.py
03_tool_origin_z_known_plane.py
04_tool_x_axis_direction_parallel_line.py
```

这套方案是“可证明、可评价、可迭代、可工程化”的。
